对当前用途，30V/10A比60V/5A更贴合：大多数SBC、路由器、工控板和小主机常见供电低于30V，电流余量更有实际价值。这个判断是用途匹配，不是对两型号总体品质的实验结论。

### 建议同时采购的线材

- 4mm香蕉头 → 大鳄鱼夹：主力供电线，优先纯铜硅胶线；1m左右可选16AWG，若计划长期接近10A则选14AWG并核实端子额定电流。
- 4mm香蕉头 → DC 5.5×2.5mm公头，并准备5525↔5521转接：覆盖常见工控板、路由器、小主机。
- 4mm香蕉头 → 尖针测试线，以及小钩夹/IC夹：用于小焊盘、排针和测试点，避免大鳄鱼夹误碰相邻焊点。
- 随机赠送线若线径、端子夹持或额定电流不明确，不作为10A负载的默认主线。

### 到手验收顺序

1. 空载先核对面板设置与输出开关逻辑，再用独立万用表分别测5.00V、12.00V、19.00V。
2. 用安全负载验证CV/CC切换与低电流限流，不拿未知贵板作为第一只负载。
3. 测量DC负极与机壳/AC保护地的关系；在同时连接USB-TTL、逻辑分析仪、电脑USB之前，先确认是否浮地以及各设备地线关系。
4. 给未知板上电时从较低电流限制开始，根据启动行为逐步放宽；出现限流后电压明显下掉时先排查短路、极性、接线和启动峰值，不直接把电流旋到最大。
