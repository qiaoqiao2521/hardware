## 失联原因与电源键

之前两次网络和 USB 同时停止响应。上一次启动日志分别在 13:04:50、13:34:59 记录 systemd-logind 的 `Power key pressed` 与 `Powering Off`，随后停止网络并进入关机流程。证据支持短按电源键触发关机，不能把这些失联直接判为 Wi-Fi 模块崩溃。

新增 `/etc/systemd/logind.conf.d/20-gm800-power-key.conf`，设 HandlePowerKey=ignore，并完成重启。短按不再由 logind 发起关机；可在桌面菜单或终端主动关机。没有修改长按的硬件行为，也没有测试长按。

## 桌面、音频与摄像头补充验收

2026-10-08 后续检查，2026-10-09 同步档案。以下为此前现场结果，本次同步没有重新连接设备测试。

- 免唤醒密码：用户级 `~/.config/autostart/light-locker.desktop` 设置 `Hidden=true`，保留账户密码。下一次进入 Ubuntu 后，DPMS 熄屏三秒再恢复，会话 `Active=yes`、`LockedHint=no`，无锁屏程序；用户确认直接回到桌面，无需密码。
- 扬声器：通过 `aplay -D plughw:0,0` 播放本地生成的《小星星》旋律，程序正常退出；用户确认声音清楚正常。检测工具只解压到用户目录，没有安装系统软件包。
- 摄像头：HI846，实体 `m00_f_hi846 2-0020`，经 `/dev/video1` 的 `rkisp_selfpath` 成功采集一帧 640×480 NV12，大小 460800 字节。转换图像后可见真实画面，但偏暗、偏绿；当时未运行 RKAIQ 自动曝光/白平衡服务，画质与完整相机应用仍待验收。采集后恢复原 1920×1080 NV12 格式。
- 存储：`lsblk` 显示内部磁盘 116.5 GiB；`df` 显示数据文件系统约 109 GiB、已用 4.9 GiB、可用 104 GiB。Ubuntu 根目录与 Android userdata 使用同一 ext4 分区，两个系统共用剩余容量；该可用值是当时快照。
- 安卓卡顿：Mali-G52 GLES 正常。B 站累计 UI 帧超时比例 96.55%；返回桌面后 CPU 空闲约 92%。支持 B 站当前页面或播放状态与高负载有关，未确认所有应用卡顿的根因，也未宣称已修复。

证据保留于本机 `下载/硬件研究/GM800/install-2026-10-08/progress.md` 的“Ubuntu 锁屏、音频与摄像头现场验证”及其 `hardware-check/`。摄像头图像包含私人环境，只保留本地，不入库。此前网络与 NPU 快照不被这次记录覆盖。
